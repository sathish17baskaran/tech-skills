12
Operate & Architect

LLMOps + Architecture Capstone

Learn: Evaluation pipelines, tracing and observability (LangSmith, OpenTelemetry), prompt versioning, CI/CD for prompts and agents, FinOps (token budgets, caching, model routing).

Capstone – Enterprise AI Architecture Pack

  1. Reference architecture (Azure + AWS): gateway, RAG layer, agent orchestration, MCP tool layer, identity, observability
  2. ADRs: framework choice, model routing, vector store, single vs multi-agent
  3. Security & governance controls mapped to OWASP / NIST / ISO 42001
  4. Evaluation results and cost model
  5. 10-minute architecture presentation

Exams

  • Book AI-103 and/or AIP-C01 for weeks 13–14
  • Then target AI-500 (Multi-Agent AI Solutions Expert)
  • Optional governance: IAPP AIGP

Weekly Rhythm (~11 hrs)

  • 4 hrs – courses
  • 5 hrs – hands-on lab on the running project
  • 1 hr – architecture reading (cloud architecture centres, engineering blogs)
  • 1 hr – write-up (ADR / diagram / blog) to build your architect portfolio

Tips

  • Pick one primary cloud: go deep on Week 9 or 10 and keep the other as comparison.
  • DeepLearning.AI short courses, Hugging Face, Microsoft GitHub curricula and Microsoft Learn are free. Coursera and some Skill Builder labs need a subscription.
  • If a link has moved, search the course title on the provider's catalogue.
