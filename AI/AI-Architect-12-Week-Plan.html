How to Use This Plan

👣 Just follow the numbers

  1. Pick your pace: 12 weeks standard, or the 6-week fast track.
  2. Start at Week 0, or Week 1 if you already code in Python.
  3. Do the numbered steps from 1 to the last one, in order. Each step is one link.
  4. Tick "Done" on the week, then go to the next week.

🧭 What the step labels mean

  • ▶ Watch a short video for the big picture. Always first.
  • 🎓 Course learn hands-on with guided lessons and code.
  • 📄 Read official docs: the source of truth (skim, then go back when you need detail).
  • 🛠 Build add this week's feature to your running project.
  • 📘 Revise / 🏅 Exam lock in what you learned.

The "All resources" box under each week's steps is only for extras. You can ignore it.

🚀 How to learn faster

  • Build first. Start each week's lab on day 1. Use the courses only to get unstuck.
  • Skip anything tagged Optional on the fast track.
  • Already know a topic? If you can already do the lab, skip that week's courses and just do the lab and docs.
  • Watch videos at 1.25–1.5× speed. Always start with the ⭐ one.
  • Keep one running project. Each week extends it, so you never start from scratch.
  • Use an AI assistant as a tutor. Ask it to explain errors and quiz you at the end of each week.
  • Book the exam on day 1. A fixed date keeps the pace up.

⏰ Daily routine (fast track)

  • Weekdays (~2.5 hrs): 30 min video, 90 min building, 20 min docs, 10 min notes
  • Weekend (~4–5 hrs/day): finish the lab, write the ADR or diagram, and do a self-quiz
  • End of week: explain the topic out loud in 2 minutes. If you can't, revisit the ⭐ video and docs.
  • Revise for interviews: flashcards and quiz on this site
